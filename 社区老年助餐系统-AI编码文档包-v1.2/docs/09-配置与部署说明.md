# 09 配置、部署与运行

> **版本优先级**：本文件保留运行步骤，具体版本安装与冻结要求以 `11-Ubuntu环境与版本锁定.md` 为准。

## 1. 运行环境

Ubuntu 26.04 LTS、Java 17（Ubuntu OpenJDK 17.0.20.1）、Maven 3.9.11、Node.js 22.22.1、npm 10.9.4、MySQL 8.4.11。完整固定版本及初始化模板见 `11-Ubuntu环境与版本锁定.md`。开发工程 `server/`、`web/`、`docs/`；首版只需本地运行，不要求 Kubernetes、Docker、Redis、Python。

## 2. 建议配置

```yaml
# server/src/main/resources/application-dev.yml 示例，所有密码必须从环境变量获取；本地可读取 templates/.env，勿提交 Git
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/elder_meal?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
    username: ${DB_USER:root}
    password: ${DB_PASSWORD}
  servlet:
    multipart:
      max-file-size: 5MB
      max-request-size: 10MB
app:
  timezone: Asia/Shanghai
  upload-path: ./uploads/private
  payment-mode: mock
  order-payment-timeout-minutes: 15
  booking-days-ahead: 7
  cutoff-before-meal-minutes: 120
  forecast-history-days: 56
  forecast-days-max: 7
```

**生产要求**：必须关闭 mock pay 开放接口；TLS、密钥环境变量、数据库备份、文件访问鉴权、操作审计、允许的 CORS 域名、支付渠道商户签约；不在仓库提交任何密钥或证件图片。

## 3. 初始化和启动

1. 创建数据库 `CREATE DATABASE IF NOT EXISTS elder_meal CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;`。
2. 在该库执行 `docs/04-数据库设计.sql`（基础 schema）。
3. 在项目实现的 seed 脚本中写入四类测试角色、演示用户、至少两个网点、若干菜品和过敏原、历史营业日及核销人数，不能写死生产密码。
4. 启动 Spring Boot `./mvnw spring-boot:run -Dspring-boot.run.profiles=dev`（需项目提供 Maven Wrapper），访问 OpenAPI 文档。
5. 启动 Vue：`npm ci && npm run dev`，配置 `VITE_API_BASE_URL=http://localhost:8080/api/v1`。
6. 用四类账号验证菜单和各自业务流程。

## 4. 最低监控和备份

- Spring Boot 应用日志与审计分开；健康检查 `GET /actuator/health` 可选用 Spring Boot Actuator。
- 每日 MySQL 备份、附件目录备份、恢复验证；预测结果可重算，订单支付退款记录不能随意删改。
- 生产演示不能使用模拟支付当真实支付。
