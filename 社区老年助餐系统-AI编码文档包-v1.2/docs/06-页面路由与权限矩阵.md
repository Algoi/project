# 06 页面、路由与权限矩阵

统一登录 `/login`。各角色首页分别 `/admin`、`/canteen`、`/family`、`/community`。一个账号如有多角色，登录后提供角色切换但权限由后端决定。管理员跨网点，其他员工需要选当前授权网点。家属端移动适配/大字。

## 5. 权限实施细则

- 页面路由仅控制 UX；Controller 和 Service 必须验证 `ADMIN` / `CANTEEN` / `FAMILY` / `COMMUNITY` 以及资源归属。
- CANTEEN：可操作本网点菜谱、出餐、备餐、核销、配送；不能管理补贴或读取所有老人健康档案，只返回配送必要的禁忌摘要。
- COMMUNITY：可操作本网点档案、补贴、代订餐、日菜谱确认、订单异常、退款、核销、工单、膳食报告；不能修改全局菜品价格或推荐算法参数。
- FAMILY：必须经绑定审核才能读取某老人详情、下单及查看报告；只可查看本人提交的反馈、本人有权访问的订单和账单。
- ADMIN：完整管理及统计能力；对个人健康信息详情无默认浏览入口，必须确有业务需要时另行授权与审计。
- 数据权限应针对订单所属网点、老人所属网点、家庭绑定和公告目标分别校验；切换 URL ID 不得导致越权。
