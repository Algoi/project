# 01 需求规格说明书（SRS）

## 1. 产品范围

目标：通过四角色 Web 系统完成社区老年助餐管理，按历史就餐时间序列生成未来人数预测，并基于老人健康信息对可售菜品进行规则过滤和评分推荐。角色：系统管理员（ADMIN）、食堂工作人员（CANTEEN）、老年人家属（FAMILY）、社区操作员（COMMUNITY）。

术语：老人（助餐受益人）；网点（社区食堂服务单位）；菜品库（全局标准菜品）；每日菜谱（网点某日可售菜品及数量）；餐次（默认为午餐，可配晚餐）；核销（实际取餐确认）；补贴价（老人适用的展示价格，具体优惠来源见业务规则）；预测（统计时间序列，不涉及模型训练）。

## 2. 系统管理员需求

- **A01 用户权限管理**：管理全部系统账号的增查改、启停、密码重置；为账号配置四类角色；配置菜单、操作以及网点数据范围；未经授权的 API 返回 403。验收：不同角色菜单和 API 生效，网点隔离有效。
- **A02 菜品价格与菜品库维护**：增查改停用全局菜品，分类、图片、主要食材、标准重量 g、过敏原、营养成分（每份能量 kcal、蛋白质/脂肪/碳水 g、钠 mg）、老人补贴价及社会原价。验收：价格非负，过敏原及营养被推荐与报告复用。
- **A03 公告发布管理**：创建/编辑/发布/撤回停餐及活动等公告；设定接收角色和/或网点，按目标群体可见。验收：指定范围外用户无法读取。
- **A04 数据可视化看板**：按日期和网点统计订单量、营收、补贴发放金额；历史实际就餐人数与未来预测折线；老人膳食统计图和菜品智能推荐效果（推荐展示次数、被推荐菜品订单转化）；不对没有统计意义的值作强结论。验收：数据可核对订单/补贴/核销原始记录。
- **A05 服务网点管理**：维护名称、地址、电话、负责人、营业/停餐状态及服务范围描述；绑定网点人员。验收：关联员工只可见授权网点。
- **A06 操作日志审计**：记录登录、用户/权限修改、补贴审核、价格、订单异常、退款、核销、健康档案改动、算法规则变更等操作的时间、操作者、对象、结果；支持筛选。验收：关键操作可追溯，日志不含密码及完整健康明文。
- **A07 膳食推荐算法参数配置**：可设置营养适配、偏好、历史评分、历史选菜权重；维护疾病禁忌菜品/食材规则与过敏原规则，查看生效版本。验收：修改后下一次推荐按新配置计算，修改可审计。

## 3. 食堂工作人员需求

- **C01 菜谱提交上报**：为所属网点提前选择次日菜品并录入/核对每份克重、过敏原、营养成分；系统显示次日人数预测及备餐参考量；可上报/修订。验收：次日菜谱记录可追溯，推荐字段完整。
- **C02 备餐出餐清单**：按菜品汇总已支付有效订单份数，显示时序预测人数与建议备餐份数；按网点、日期、餐次生成/打印。验收：已取消或退款订单不计入有效份数。
- **C03 现场就餐核销**：使用电子凭证或订单号核验堂食/外带，校验所属网点、状态并防重；实时写核销记录。验收：同一份取餐凭证重复核销失败。
- **C04 配送清单生成**：按日/网点列出送餐订单，生成可打印单据，标注与本订单相关的过敏原、特殊饮食需求；只向有权限人员展示必要信息。验收：非配送订单不进入配送单。
- **C05 菜品评价查看**：查看所属网点菜品评分、文字、图片、差评及筛选。验收：只看到本网点有效评价。
- **C06 公告查看**：查看分发给食堂角色/本网点的公告及重要通知。验收：范围正确。
- **C07 备餐预测查询**：查看本网点未来多日预测和历史实际趋势，辅助采购计划；展示日期与人数。验收：无训练页面，只显示统计预测结果。

## 4. 老年人家属端需求

- **F01 老人信息绑定与补贴申请**：绑定已有老人或发起建档申请，上传资格材料，填报健康情况与饮食禁忌，查看审批状态；避免任意绑定他人。验收：未验证的关联不能读取隐私或下单。
- **F02 家属代订餐**：大字友好界面展示菜品与补贴后应付金额；按健康档案过滤已知过敏原/明确禁忌；对剩余菜品个性化排序并说明原因；选日期、餐次、堂食/外带/配送。验收：禁忌菜不可加入订单且服务端重复校验。
- **F03 在线支付**：支付订单，渠道可配置（至少模拟多个渠道供测试），显示账单明细、原价、补贴及实付；回调校验与幂等。验收：重复回调不重复入账。
- **F04 订单管理**：查询状态、明细；未出餐且符合截止规则可取消，已支付取消时进入退款；展示电子凭证。验收：出餐后不可直接取消。
- **F05 菜品评价**：核销完成后对订单菜品评分、文字及图片反馈；防止对未消费菜品评价。验收：同一订单明细同一人仅一条有效评价。
- **F06 意见反馈**：创建问题/投诉工单，查看处理状态、处理回复、进度。验收：只能读取本人提交的工单。
- **F07 公告查看**：首页展示停餐等重要公告，可查看正文与历史公告。验收：公告针对老人关联网点/家属群体过滤。
- **F08 个人中心**：个人信息、密码、绑定老人列表、订单与消费账单、个人偏好设置。验收：权限隔离。
- **F09 膳食报告查看**：按周/月查看已核销订单汇总的营养摄入估算与趋势；明确展示“仅统计本系统记录的餐食，不能视为完整每日摄入”。验收：无核销数据展示暂无数据，不编造营养结果。

## 5. 社区操作员需求

- **O01 老人档案管理**：建立并维护所属范围老人基础档案、健康信息、禁忌、基础疾病，提供推荐数据，变更可追踪。验收：越权编辑拒绝。
- **O02 老人补贴资格审核**：核对身份和申请材料，批准或驳回、填写理由；批准后权益生效，审核记录保留。验收：非操作员不可审批，不能自审批绕过权限。
- **O03 老人代订餐服务**：协助老人单日或周期订餐；按健康约束推荐并过滤菜品；订单记录代办人；周期预订生成各日独立订单。验收：所有日期逐日检查可售和禁忌。
- **O04 每日餐品维护**：确认本网点当天可售菜品、临时下架问题餐品；下架后禁止新增订单但不静默删除既有订单。验收：库存/数量检查有效。
- **O05 网点订单处理**：按本网点查看所有订单，筛选并处理明确的异常订单（联系记录/标记异常、取消申请等），不能任意改支付成功。验收：所有变更有日志。
- **O06 退单退款审核**：查看退款理由、订单与补贴记录；审核批准/驳回，避免重复退款与补贴骗领。验收：退款金额不超已支付，补贴记录只回滚一次。
- **O07 取餐核销核验**：现场核对老人和凭证执行核销；支持人工核实方式，记录经办人。验收：与工作人员共用相同核销规则，防重复。
- **O08 投诉工单处理**：查看本网点工单、设置受理/回复/办结、超时提示和重大问题上报管理员。验收：工单处理轨迹可见。
- **O09 公告查看**：接收上级公告，按权限查看详情。验收：范围正确。
- **O10 老人膳食分析**：查询本网点关联老人的实际用餐历史，查看周/月膳食分析和注意事项，不生成诊断意见。验收：不跨网点读取健康数据。

## 6. 公共约束与非功能需求

- 权限：后端接口必须实现角色 + 所属资源（网点/老人绑定）的双重鉴权；个人健康信息仅最小授权访问。
- 支付/退款/核销：幂等、防重、事务与审计；金额统一使用 DECIMAL(10,2)，禁止浮点计费。
- 上传：图片/材料限制扩展名、MIME、大小，随机文件名，私有附件经鉴权下载。
- 可靠性：预测失败时展示“暂无预测”并允许按真实订单备餐；推荐失败时仍可在安全规则校验后浏览安全候选菜品。
- 展示：移动适配、家属端大字号，关键金额和订单状态明显；关键空态、加载态、失败态完整。
- 性能建议：普通分页接口在测试数据量下 2 秒以内、核销事务在正常环境 2 秒内；性能目标按实际部署调整。
- 隐私：保护证件材料、手机号、健康资料；审计不记录敏感原文，导出的配送单只包含必要信息。

## 7. 明确排除项

不做原生 App、小程序独立实现、短信自动提醒、电子医疗记录接入、在线医生、复杂营养治疗方案、复杂采购库存管理、配送路由优化、算法自动训练与实验平台、机器学习/深度学习模型、复杂财务 ERP。
