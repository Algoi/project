# 第四批验收：生命周期、菜谱模板与导出

老人服务状态在社区档案编辑中维护。家属可撤回/解除本人绑定，授权社区可撤销关系；绑定申请、审核、撤销写入独立历史，关系失效后档案、地址和订单访问权限收回，财务台账保留。补贴支持起止日期、终止及历史；推荐价格和下单核算均按用餐日期判断，历史订单快照不被重算。

食堂可复制菜谱和保存/应用周模板。模板保存所选周一至周日已有可售餐次，应用全部在同一事务，目标冲突或当前菜品失效时回滚，不覆盖已有菜单。所有复制结果均为草稿，仍需核对、上报、社区发布。

通用列表与专用账单支持按当前筛选导出全部匹配记录，备餐可导出当前清单。分页导出逐页使用原权限接口，数组列表采用同一显示字段筛选。CSV 使用 UTF-8 BOM、引用转义和公式字符防护。

三项关键后端测试先失败（含补贴日期错误价格复现），实现后与上一批、模块及 API 检查共 11 项通过。导出 2 项测试通过；前端 32 项、类型检查与构建通过。专用新网点在真实 Chrome 验证复制→周模板→新周草稿→CSV 下载；新家属验证解绑→历史。桌面、手机均通过。证据 `enhancement-04-server.txt`、`enhancement-04-05-browser.txt`、`enhancement-04-export-test.txt`。

最终审核额外验证了第二个餐次发生冲突时首个餐次也会回滚。该用例最初在测试外层事务内观察未提交数据导致误报，已移至独立 MenuTemplateAtomicityTest，跨实际服务事务观察失败后的数据库状态，全量通过。绑定管理列表继续保留审核证明文件字段。
