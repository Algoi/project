## 局域网访问

本机网卡 `ens33` 地址为 `192.168.0.128/24`。修改前前端只监听 `127.0.0.1:5173`，通过 `192.168.0.128:5173` 连接失败。

`web/vite.config.ts` 的 `server.host` 改为 `0.0.0.0`，Vite 自动重新启动监听；已核对实际监听为 `0.0.0.0:5173`，该局域网地址 HTTP 返回 200，原本机地址继续可用。API 继续使用同源 `/api` 代理，不需要改成局域网后端地址。

类型检查通过。通过本机 Chrome 访问局域网 IP，四角色桌面/手机登录、刷新、角色隔离和退出共 8 项测试全部通过（43.4 秒），结果见 [局域网浏览器记录](lan-browser-results.txt)；这验证了服务器按该地址提供服务，其他设备到服务器之间的网络仍取决于现场连接。

统一启停脚本不变：`./scripts/service.sh start|stop|restart|status`。当前 IP 及访问方法已补入 README。

后续算法体验检查进一步复现并修复了局域网 HTTP 的订餐页初始化问题，已补缺少 `randomUUID` 时的回归测试及局域网完整流程验证，见 [算法说明验证](algorithm-testing.md)。上述 8 项登录测试本身未覆盖订餐页面。
